# ダウンロード先振り分け

Chromeでダウンロードしたファイルを、URLまたは拡張子のルールに応じて自動的にフォルダ分けする拡張機能です。

- URLまたは参照元URLに含まれるキーワードで振り分け
- ファイルの拡張子で振り分け
- ルールの追加、編集、削除
- 設定のエクスポート、インポート
- 拡張機能の有効・無効をアイコンから切り替え

## インストール

### Chrome Web Storeからインストール

Chrome Web Store [ダウンロード先振り分け](https://chromewebstore.google.com/detail/%E3%83%80%E3%82%A6%E3%83%B3%E3%83%AD%E3%83%BC%E3%83%89%E5%85%88%E6%8C%AF%E3%82%8A%E5%88%86%E3%81%91/iglokmjaapadipghfmnjhlbobgeicbpa) からインストールできます。

### GitHub Releasesからインストール

Chrome Web Storeを利用せずにインストールする場合は、[Releases](https://github.com/swirhen/chrome-extensions/releases)から最新版のZIPファイルをダウンロードします。

1. ZIPファイルを展開します。(展開の際、任意の名前でフォルダを作成してください)
2. Chromeで `chrome://extensions` を開きます。
3. 右上の「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を選択します。
5. 1. で展開したフォルダを選択します。

## 使い方

1. 拡張機能をインストールします。
2. 拡張機能の詳細画面から「拡張機能のオプション」を開きます。
3. URLまたは拡張子と、保存先フォルダ名を登録します。
4. ファイルをダウンロードすると、ルールに応じて保存先が決まります。

URLルールが拡張子ルールより先に適用されます。URLルールに一致しない場合に、拡張子ルールが適用されます。

### URLルール

URLまたは参照元URLに指定したキーワードが含まれる場合に適用されます。キーワードはカンマ区切りで複数指定できます。

例:

- キーワード: `example.com`
- 保存先フォルダ: `Example`

### 拡張子ルール

URLルールに一致しない場合、ファイルの拡張子に応じて適用されます。拡張子はカンマ区切りで複数指定できます。先頭の `.` は省略できます。

例:

- 拡張子: `jpg, png, gif`
- 保存先フォルダ: `Images`

### ダウンロード先をDownloads配下以外にしたい方へ

Chromeの仕様上、ファイルのダウンロード先はDownloads配下以外には設定できません。

ヒントとして、シンボリックリンクをDownloads配下に作成すれば、Downloads配下以外のフォルダにも保存することができます。

Windowsの例:

```powershell
New-Item -ItemType SymbolicLink `
  -Path "$HOME\Downloads\Images" `
  -Target "D:\Files\Images"
```

シンボリックリンクの作成には、環境によって管理者権限が必要な場合があります。

## 他のダウンロード・クローリング系拡張との競合

ページをクローリングしてファイルをダウンロードしたりする拡張と相性が悪いです（競合します）

例：PixivFanboxDownloader など

そのような拡張を使う場合はこの拡張機能のアイコンをChromeに固定しておいて、クリックで無効化して下さい。

## 設定のバックアップ

設定画面の「設定をエクスポート」でルールをJSONファイルに保存できます。「設定をインポート」で保存したJSONファイルを読み込めます。

## 開発

このリポジトリの `dl_shiwake` フォルダが拡張機能本体です。

```text
dl_shiwake/
  manifest.json
  background.js
  options.html
  options.js
  icons/
```

ソースを変更した場合は、次の手順で動作を確認します。

1. `chrome://extensions` を開きます。
2. 対象拡張機能の更新ボタンを押します。
3. 必要に応じて設定画面を開き直します。
4. ダウンロードを実行して振り分けを確認します。
